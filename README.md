# Heart Disease Prediction Using Machine Learning

This project focuses on using Python and machine learning to analyze the Heart Disease dataset and predict whether a patient may have heart disease.

I used Google Colab to prepare the dataset, train a Random Forest model, improve its performance through hyperparameter tuning, and evaluate the results.

The project also discusses ethical considerations and how AI could potentially support healthcare professionals.


## Tools Used

- Python
- Google Colab
- pandas and NumPy
- Matplotlib and Seaborn
- scikit-learn

## Project Results

The notebook includes model evaluation metrics, a confusion matrix, and a comparison between the original and optimized models.
